# Release v0.1.11

## ✨ Highlights

- **Persona consistency enforcement**: multi-layered pipeline fixes prevent AI persona drift during complex prompts, session resets, and extended thinking.
- **Selfie tool refinements**: caption parameter, post-selfie text suppression, and identity violation filtering.
- **TTS voice configurability**: voice ID now configurable via `config.json` instead of hardcoded.
- **Critical LLM behavior fixes**: approval loop recovery, tool capability denial prevention.

## ➕ Added

- Paragraph-aware identity filter: surgically strips only violating paragraphs instead of blanking entire response.
- 18 new identity denial patterns covering memory denial (`ingatan permanen`, `di luar konteks chat`) and capability denial (`nggak bisa ngarang`, `gak bisa generate`).
- Trailing question stripping in persona sanitizer — prevents constant question-ending while keeping genuine questions.
- `_build_tool_awareness()` injects registered tool names into system prompt to prevent capability denial.
- `tts_voice` field in `ToolsConfig` schema (default: `id-ID-GadisNeural`).
- Selfie `caption` parameter for natural, in-character photo captions.
- `docs/persona.md` documenting persona system, SOUL.md structure, and selfie protocol.
- Expanded test coverage for identity filtering, pipeline order, and voice delivery.

## 🔄 Changed

- **Critical pipeline reorder**: persona sanitizer now runs as the FINAL step before `OutboundMessage` — no subsequent step can override sanitized output.
- Identity filter now applies to ALL responses, not just selfie tool path.
- Memory truth fallback rewritten from formal system message to Keiya-style natural Indonesian: `aku inget kok. tanya aja, nanti aku cek.`
- Few-shot priming examples: only 1/4 ends with a question (statement-ending persona pattern).
- SOUL.md template: added rules against question-ending (max 30%), multi-question, and service-oriented phrases.
- Approval-denied error messages now use casual Indonesian to preserve persona.

## 🐛 Fixes

- Fixed persona drift during complex/long-thinking prompts (capitals, bullet points, AI-like phrasing).
- Fixed AI claiming "no persistent memory" or "can't generate images" despite having the capability.
- Fixed approval loop where user typed `approve exec` but LLM lost context of pending command.
- Removed unused `import re` and extraneous f-string prefix (Ruff F401, F541).
