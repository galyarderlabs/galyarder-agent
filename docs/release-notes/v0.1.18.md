# Release v0.1.18

## Highlights

- **CI test portability repair**: backend Web UI tests now create their own static index fixture instead of depending on untracked local build artifacts.

## Fixes

- Fixed `tests/test_webui.py::test_webui_index` returning `404` in fresh GitHub Actions checkouts where `g_agent/webui/dist` is absent.
- Kept runtime Web UI behavior unchanged: `/` is served only when a built `webui/dist/index.html` exists.

## Verification

- `backend/agent/.venv/bin/python -m pytest -q backend/agent/tests/test_webui.py` passed with 2 tests.
- `backend/agent/.venv/bin/python -m pytest -q backend/agent/tests` passed with 454 tests.
- `python -m ruff check backend/agent/g_agent backend/agent/tests --select F` passed.
- `python -m compileall -q backend/agent/g_agent` passed.
- `mkdocs build --strict` passed.

## Notes

- The previous `v0.1.17` tag fixed dependency installation but still failed backend tests on GitHub Actions due to the Web UI static artifact assumption. This patch release avoids rewriting the existing tag.
